# EC2 Agent Platform

Build an extensible, policy-controlled Minecraft agent that operates the owned live server through unprivileged host capabilities while keeping infrastructure, root, metadata, unrelated host paths, and deployment secrets outside the agent boundary.

The current milestone is one capable operator for one server. Reduce overlapping coordination/recovery machinery and
qualify actual packaged execution before expanding into multi-server or fleet features. Shared authority protocols have
one owner; the feature PRD, not the older competitor roadmap, defines the release gates.
