# Live Server Agent Foundation

**Status:** Replanned; implementation candidate, not release-ready.

Deliver a generalized confined shell/file/console agent for one actual server, with a replaceable harness, useful
portal tasks, exact approvals, working extensions and durable effect evidence. No mandatory duplicate world.

The PRD replaces the old parallel task sequence with gates G0-G5: freeze/inventory, stabilize prerequisites, complete
capability, prove packaged composition, review a frozen candidate, and prepare an explicitly authorized handoff.
Actual subprocess/socket/service and failure-boundary evidence is required; cloud-free mock tests alone are insufficient.
Activation scope, real compatibility obligations, plugin-install scope and the approved offline runner must be resolved
before qualification. Do not resume all interrupted engineers unchanged or infer deployment authorization from this plan.
